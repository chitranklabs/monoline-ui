## Install

<Tabs id="package-manager" labels={["npm", "pnpm"]}>
	<pre slot="npm">
		<code>npm install @chitrank2050/ask-widget</code>
	</pre>
	<pre slot="pnpm">
		<code>pnpm add @chitrank2050/ask-widget</code>
	</pre>
</Tabs>

## Render the widget

```tsx
import { ChatWidget } from "@chitrank2050/ask-widget"
import "@chitrank2050/ask-widget/style.css"

export function App() {
	return <ChatWidget apiUrl="https://api.example.com" />
}
```

Without `apiUrl` or `streamResponse`, the component uses its demo response.
Production integrations should provide an SSE endpoint or a custom handler.
