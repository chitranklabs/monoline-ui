## Custom streaming

```ts
export type ChatStreamResult =
	string | AsyncIterable<string> | Promise<string | AsyncIterable<string>>

export type ChatStreamHandler = (
	message: string,
	history: ChatMessage[]
) => ChatStreamResult
```

When `streamResponse` is set, it owns request and streaming behavior; `apiUrl`
and `apiToken` are ignored.
