## Custom streaming

<span id="chatstreamhandler-type" />

```ts
export type ChatStreamResult =
	string | AsyncIterable<string> | Promise<string | AsyncIterable<string>>

export type ChatStreamHandler = (
	message: string,
	history: ChatMessage[]
) => ChatStreamResult
```

When `streamResponse` is set, it owns request and streaming behavior; `apiUrl`
and `apiToken` are ignored.

### Example Usage

```tsx
const streamResponse = async function* (message) {
	yield `Local response: ${message}`
}

<ChatWidget streamResponse={streamResponse} />
```
