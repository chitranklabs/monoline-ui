Use Node.js 24.14 or newer. Install Monoline Docs from npm in a new or existing project directory.

## Create a site

<Steps>
<Step>
Install the package in your project and initialize the site:

```sh
npm install @chitrank2050/monoline-docs
npx monoline-docs init
```

For pnpm, use `pnpm add @chitrank2050/monoline-docs` followed by `pnpm exec monoline-docs init`.

</Step>
<Step>
Start the local preview:

```sh
npm run dev
```

Open the address printed in your terminal.

</Step>
<Step>
Edit `content/index.md`. Changes to content and assets rebuild the preview automatically; restart it after changing configuration.
</Step>
</Steps>

The initializer creates the configuration, homepage and build/dev scripts. Existing conflicting configuration, homepages or scripts are rejected rather than overwritten. It does not install dependencies.

## Write a page

Create `content/installation.md`:

```markdown
---
title: Installation
description: Set up your project.
---

## Install

Follow the installation instructions for your project.
```

With generated navigation, the page appears in the sidebar. Read [Writing pages](writing.md) for links, headings and MDX.

## Build and publish

```sh
npm run build
```

Your static site is written to `dist`. Deploy this directory to a static host; follow [Deployment](deployment.md) for base paths and hosting recipes.
