## Grow with your project

Start with ordinary Markdown. Use [authoring components](/components) for installation steps, guide cards, code tabs and reference tables. Add [generated OpenAPI documentation](/openapi) when your project has an API specification.

The same published content powers [local search](/search) and [Markdown and AI exports](/exports).

## What to expect

Basic reading and navigation work without JavaScript. Search, copying and enhanced tabs use the shared client script; React is optional for explicitly hydrated custom examples.

There is one built-in design, configurable through branding and appearance settings. See [supported environments and limitations](/support) before adopting it.

The package is not published yet. [Getting started](/getting-started) explains how to evaluate a locally packed build.
