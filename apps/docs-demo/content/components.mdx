Use Markdown for prose, headings, lists, links, tables and fenced code. Choose MDX when a page needs reusable structure such as installation steps, topic cards or package-manager tabs.

## Import into MDX

```mdx
---
title: Install your project
---

import PackageInstall from "@chitrank2050/monoline-docs/components/PackageInstall.astro"

<PackageInstall id="install-project" name="your-package" />
```

Component names and paths match the public imports. The `id` identifies a group within the page; keep it unique.

## Static content and interactions

Astro components render as HTML. Native disclosures work without JavaScript; tabs and copy controls enhance the page through the shared script. React is optional for custom hydrated examples—see [Writing pages](/writing).

Preview examples keep link activation and form submission on the current page when JavaScript is available. This protects the demonstration; ordinary links outside previews navigate normally.
