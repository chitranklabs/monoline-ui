## Usage

The copy action copies raw source. Overflow is keyboard-scrollable. Without JavaScript the source remains readable and the copy control stays hidden.

## Behavior and accessibility

The copy control copies source without line numbers. Code can be selected manually without JavaScript; long lines remain horizontally scrollable.
