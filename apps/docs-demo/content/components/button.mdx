## Accessibility and behavior

Use the `leadingIcon` and `trailingIcon` slots for decorative icons in any variant.

Uses native buttons and links. Standard HTML attributes pass through, including accessible labels and form attributes. Keyboard focus remains visible, mobile controls have 44px tap targets, and transitions respect reduced motion. No JavaScript is needed to render the component.
