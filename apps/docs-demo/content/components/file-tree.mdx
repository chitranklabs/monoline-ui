## Usage

Folders use native disclosures and default to expanded. expanded applies only to folders; highlight marks a file or folder. Cycles and more than 20 nested folders are rejected.

## Behavior and accessibility

Folders use native details controls. Enter or Space toggles the focused folder; file labels remain readable without JavaScript.
