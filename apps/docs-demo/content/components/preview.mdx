## Usage

The default slot contains the rendered example. Use `source` and `language` for the faded, expandable code presentation, or the `code` slot for custom source content. Set `showCaption={false}` when the surrounding section already describes the example; the title remains its accessible name. Source and the code slot cannot be combined. Snippets of up to four lines show in full with no fade or View code control; longer snippets use the expandable preview. Consumer preview styles are excluded from article typography. React hydration is explicitly authored with Astro client directives.

## Behavior and accessibility

Preview frames display authored content; mode labels do not hydrate it. Link activation and form submission inside rendered previews stay local when JavaScript is available.
