## Usage

Import `Table` from `@chitrank2050/monoline-docs/components/Table.astro`.
Column keys read values from each row. Labels and content are supplied by the author;
props, variables, queries and other structured data use the same component.
Set `format: "code"` for code cells. Missing and null values display an em dash.

## Compact

Use `variant="compact"` when the content needs less cell padding. The default has the standard documentation spacing.

<Preview
	title="Compact table"

## Props reference

Use `variant="reference"` for technical fields. Define a Default column for props;
use a Required column for type fields. Both use the same Table and visual variant.

## Accessibility

The first column supplies row headings; column headings and captions use native table semantics.
Overflow remains keyboard-scrollable. Cell content is escaped text.

Use this same component for API props, type fields and other tabular data by supplying the appropriate columns.
