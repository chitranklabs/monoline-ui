Use Accordion for optional explanations, FAQs and troubleshooting details.
Keep essential instructions visible in the article so readers can find them
without opening a disclosure.

## Usage

Import the component in an MDX page or an Astro component. It is included in
Monoline Docs; no additional UI library or React setup is required.

`"astro\nimport Accordion from \"@chitrank2050/monoline-docs/components/Accordion.astro\"\n\n<Accordion title=\"More details\">\n  <p>Place supporting content here.</p>\n</Accordion>"`

In MDX, put imports after the page's frontmatter. Inside an `.astro` component,
put the import in its frontmatter script and the markup in its template.
Plain `.md` pages cannot import components.

## Initially open

Use `open` to reveal the content on first arrival. Readers can still close it.

The default slot accepts paragraphs, lists, links and other static content.
Keep interactive controls inside the content, away from the title.

## Multiple items

Place multiple Accordions together for a short FAQ. Each item opens and closes
independently, so readers can keep several answers visible. Exclusive opening,
disabled items and controlled React state are not part of this component's API.

The **default slot** holds the disclosure content. There are no named slots.
An empty title or a non-boolean `open` value fails the build with a validation error.

## Accessibility and behavior

- **Keyboard:** Tab focuses the title; Enter or Space toggles its content. Links
  and controls inside the content enter the tab order when the item is open.
- **Semantics:** Native `details` and `summary` communicate the expanded state.
  No additional ARIA roles or client directives are needed.
- **Without JavaScript:** Opening, closing and reading work with scripts disabled.
- **Motion:** The disclosure uses the native browser behavior and has no animated
  height transition. The focus indicator remains visible.
- **Page contents:** Accordion titles are controls, not article headings, and do
  not appear in the page's table of contents.
