## Usage

Import both `Steps` and `Step`. `Steps` creates the ordered procedure; `Step` supplies each instruction. Neither component accepts configuration props. Its default slot holds the content.

Steps renders an ordered list. Put Step children in its default slot; use it only when order matters.

## API reference

This component has no public props. Its default slot contains the child content described above.

## Behavior and accessibility

Steps renders an ordered list; Step is its list item. Use this pair when sequence matters, and give each step a concrete action.
