## Usage

Commands are generated for npm, pnpm, Yarn and Bun. Samples use an illustrative package name; replace it with your actual dependency.

## Behavior and accessibility

Replace illustrative package names with your actual dependency. The generated commands are text for readers to copy; the component does not install packages.
